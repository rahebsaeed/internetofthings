# دليل النشر على Wix — صفحة درس أجهزة إنترنت الأشياء

الملفات الجاهزة في هذا المجلد:
- `index.html` — الصفحة كاملة (RTL، متجاوبة مع الجوال، نشاط تفاعلي بأسئلة صحيحة/خاطئة، فيديوهات، معرض صور ومصادر).
- `media/` — كل الوسائط المستخدمة: 13 صورة + 5 رسوم متحركة (GIF) + مقطعان MP4.

---

## الطريقة الأولى (موصى بها): تضمين الصفحة داخل Wix

Wix لا يسمح برفع ملفات HTML كموقع كامل مجانيًا، لكن يمكن عرض الصفحة كاملة داخل موقعك عبر **إطار تضمين (iframe)**:

1. ارفعي مجلد `site` كاملًا إلى استضافة مجانية سريعة (أي خدمة واحدة تكفي):
   - **Netlify Drop**: افتحي app.netlify.com/drop — اسحبي مجلد `site` وأفلتيه — تحصلين على رابط مثل `https://اسم-عشوائي.netlify.app`.
   - **GitHub Pages**: أنشئي مستودعًا، ارفعي الملفات، ثم Settings → Pages → Branch: main.
2. افتحي محرر Wix لموقعك، ثم: **إضافة (＋) ← تطبيق/Embed ← تضمين HTML (iframe)** أو **"تضمين موقع" (Embed a Site)**.
3. اختاري **عنوان موقع (Website address)** والصقي الرابط من الخطوة 1.
4. اضبطي حجم рам التضمين: **متجاوب (Responsive)** أو **ملء الشاشة**، واسحبي الحواف لتملأ المساحة.
5. من **إعدادات الموقع ← اللغة**: اختاري العربية ليُضبط اتجاه واجهة Wix نفسه من اليمين لليسار.
6. اختبري زر **معاينة (جوال + حاسوب)** ثم اضغطي **نشر**.

## الطريقة الثانية: إعادة بناء الأقسام داخل محرر Wix (للتوثيق التام)

إن أردتِ مظهرًا "وix أصليًّا" لا إطارًا:

1. **الوسائط**: من مكتبة الوسائط (Media Manager) ارفعي الصور ومقاطع MP4 من مجلد `media/`. ارفعي الفيديو كـ **فيديو Wix** ليُشغَّل بخادم Wix (أفضل جودة على الجوال).
2. **الأقسام**: أضيفي أقسامًا بالنص المنسوخ من `index.html` (العناوين والأهداف، المكونات الأربعة، المستشعرات، المشغلات، التقرير المختصر، المراجع).
3. **الصور**: استخدمي شبكة صور (Gallery) بثلاثة أعمدة، وأضيفي **نص بديل/وصف لكل صورة** يذكر المصدر (مثل: "Wikimedia Commons — HC-SR04").
4. **النشاط التفاعلي**: من **إضافة ← نماذج (Forms)** أنشئي سؤال اختيار من متعدد لكل عبارة، ويمكن إظهار "إجابة صحيحة" عبر نص التغذية الراجعة لكل خيار (نص خاص).
5. **الألوان والخطوط**: اختريا خطًا عربيًّا قريبًا (Cairo / Tajawal متاحان في Wix) ولونًا أساسياً `#0B3C49` مع لون مميّز برتقالي `#FF8C00` ليطابق العرض التقديمي.

## ملاحظات تتعلق بالمهمة

- اذكري في وصف الموقع نص المهمة (اسمك، الرقم 260335، المقرر EDUC4016، د. أحمد الحوسني).
- احتفظي برابط الموقع المنشور وأضيفيه في التقرير المطبوع عند التسليم.
- كل الصور والمقاطع في الصفحة تحمل سطر مصدر داخل الصفحة نفسها (قسم المصادر + تعليقات الصور).

## تشغيل الصفحة محليًا للمعاينة

```bash
cd site
python3 -m http.server 8000
# ثم افتحي: http://localhost:8000
```
